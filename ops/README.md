# ops

Internal documentation for the people who run Atlantis Cloud: server and
control-plane configuration, the operator CLI, local development, and
architecture notes.

Deploying the platform on GCP is [`deploy/gcp/README.md`](../deploy/gcp/README.md):
the bootstrap script and manifests, in the order they run.

Nothing in this tree is customer documentation. The customer docs live in
[`docs/`](https://docs.tryatlantis.dev/) and follow [`docs/STYLE.md`](../docs/STYLE.md);
pages here are exempt from that voice standard but not from being accurate.
